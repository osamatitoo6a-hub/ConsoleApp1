# 📚 Library Management System (Console Application)

A C# Console Application built to manage library operations efficiently. Designed with separate workflows for **Users** and **Librarians**.

---

## 🚀 Features

### 👤 User Module
- Register and apply for a **Library Card**.

### 🛠️ Librarian Module
- **Add New Books**: Expand the catalog with new titles and author details.
- **Remove Books**: Manage and clean up unavailable or damaged inventory.
- **Display Books**: View all currently available library holdings.

---

## 🛠️ Tech Stack & Concepts
- **Language**: C# (.NET Core)
- **Data Structures**: `List<T>` for dynamic data storage
- **OOP Principles**: Encapsulation & Object Creation
- **Control Flow**: Clean menu loops using `switch-case` statements
